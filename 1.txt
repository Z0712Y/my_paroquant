本次改进在 ParoQuant-4 的贪心旋转量化框架上，深度融合 PrefixQuant 思想，实施了三合一方案：以任务特定的 Prefix Token 作为分布锚点，将其激活统计融入通道显著性分数以指导精准配对（方案1），在 Prefix-Stabilized 分布下逐层联合优化量化参数（方案3），并学习任务特定的角度残差解耦非推理与长思维链推理任务的最优旋转空间（方案5），最终通过角度烘焙实现同一套 4-bit 权重的任务特化推理。

===========================（3）生成可部署模型（带任务烘焙）===========================
由于三合一 .pt 包含两套角度残差，需先按任务类型烘焙，再转换：
=========Step A：烘焙 Short 角度（非推理任务）
python3 scripts/bake_task_angles.py \
    --pt-dir ./output/Qwen3-4B \
    --task-type short \
    --output-dir ./output/Qwen3-4B_baked_short

=========Step B：烘焙 Long 角度（推理任务）
python3 scripts/bake_task_angles.py \
    --pt-dir ./output/Qwen3-4B \
    --task-type long \
    --output-dir ./output/Qwen3-4B_baked_long

=========Step C：生成伪量化模型（精度验证用，存储与 FP16 一致）
# Short-path 伪量化（BoolQ/ARC/HSwag 评测用）
python3 scripts/pseudo_quant.py \
    --model /home/hhw/zy/models/Qwen3-4B \
    --result-dir ./output/Qwen3-4B_baked_short \
    --output-path models/Qwen3-4B-PARO-pseudo-short
# Long-path 伪量化（MMLU/GPQA/AIME 评测用）
python3 scripts/pseudo_quant.py \
    --model /home/hhw/zy/models/Qwen3-4B \
    --result-dir ./output/Qwen3-4B_baked_long \
    --output-path models/Qwen3-4B-PARO-pseudo-long

=========Step D：生成真实量化模型（实际部署用，存储减少 3/4）
# Short-path 真实量化

    --model /home/hhw/zy/models/Qwen3-4B \
    --result-dir ./output/Qwen3-4B_baked_short \
    --output-path models/Qwen3-4B-PARO-short
# Long-path 真实量化

    --model /home/hhw/zy/models/Qwen3-4B \
